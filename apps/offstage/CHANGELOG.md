# Offstage 変更履歴

<!-- 見出しは `## <版番号>` の形にすること (release-offstage.yml がこの節を Release の本文に使う) -->

## 未公開

- 詳細のボタンを「開く」(既定のアプリで開く) と「フォルダ」(エクスプローラーで場所を開く。これまでの「開く」) の 2 つにした。
  開くと実行される種類 (`.bat`・`.exe`・`.ps1`・`.vbs`・`.lnk` など) は「開く」を押せない

## 0.1.1

- `--refresh`: 窓を出さずに取り込んで終わる (RepoTether が起動時に裏で走らせる)。`--repo <フォルダ>`: そのリポジトリで絞って開く
- 取り込み・了解・区分の変更のたびに、記録の隣へ `summary.json` (リポジトリごとの印の数。ファイル名は書かない) を書く。RepoTether がこれを読んで行に札を出す
- 画面と裏の取り込みが同時に記録を書いても、失敗させずに待つ

## 0.1.0

最初の版。

- gitignore された手元のファイルをリポジトリごとに洗い出し、「生成物 / 機密の疑い / 道具のデータ / 個人」に分けて記録する。中身は読まない。分け方はフォルダかファイルの単位で付け替えられる
- 前回と比べて、消えた・動いた (同じ中身が別の場所に現れた)・戻った・リポジトリごと見当たらない、を印にする。「了解」で印から外す
- Claude Code の会話の記録から、ファイルが会話に出た場面と出方 (読込・添付・検索・編集・命令・作成・結果・本文) を拾う。機密の疑いのファイルの中身が会話に出たら印にする
- 会話の場面を押すと、前後のやり取りを開く。人と Claude の文は Markdown を組んで表示し、「原文」で元の文字に戻せる。種類ごとに隠せる
- git が管理する資料 (md・画像・動画・音声・Office・PDF・HTML) も一緒に探せる
- 検索・区分・状態・会話・リポジトリ・拡張子で絞る。表示は一覧とツリーを切り替える
- 通信しない (依存と CSP を試験で確かめる)。記録が同期フォルダの下なら開かない
