# Offstage 変更履歴

<!-- 見出しは `## <版番号>` の形にすること (release-offstage.yml がこの節を Release の本文に使う) -->

## 未公開

- 絞り込みの欄を並べ直した: 検索 → 期間 → 種類 → リポジトリ、区切りのあとに 区分 → 会話 → 状態。各欄の名前にアイコンを付けた
- 既定から変えた欄は、名前と枠を青く塗る。「解除」に使っている条件の数を出し、何も絞っていなければ押せないようにした
- 期間の「指定」の欄の名前を「開始」「終了」にした

## 0.1.4

- 表示に「区分」を足した。今の絞り込みに当たるものを、フォルダ (上から 1〜3 段) ごとに区分別に数え、多い順に並べる。
  行から区分をまとめて付け替え、「一覧」でそのフォルダの中だけを見る (上の札か「解除」で絞り込みを外すと、表示「区分」に戻る)
- 詳細の「理由」に、どの規則でその区分になったかをいつも出す (`data/` の中・付け替え・どの規則にも当たらない、など)
- 詳細に「リポジトリ」の欄を足した。取り込み元と自分のコミットの数を出し、自分のコミットが無ければよその写しかもしれないと添える。
  「対象外」(2 回押して確定) でリポジトリごと取り込みの対象から外し、記録からも外す。表示「区分」の下から戻せる

## 0.1.3

- 期間で絞る: 更新日時で「今日 / 7 日 / 30 日 / 90 日 / 1 年 / 1 年より前 / 指定 (日付の範囲)」
- 表示に「時系列」を足した。更新の新しい順に並べ、今日・昨日・7 日以内・30 日以内・月ごとに区切る
- ツリー: フォルダの行にリポジトリ名からの道筋 (`web-shop/sandbox/`) を薄く添え、リポジトリの行は流しても上に残す
- 不明 (フォルダごと見当たらないリポジトリ): ふだんの一覧から外し、札を「不明」にした。「不明」のカードで出し、詳細の「了解」(2 回押して確定) でリポジトリごと記録から外す
- 記録に分け方の版を残し、より新しい版が書いた記録は古い Offstage では取り込まないようにした (RepoTether に同梱の古い offstage.exe が、裏の取り込みで分け方を戻さないように)
- 更新日時を「10 分前」「昨日」「3 日前」のように出す (元の日時は吹き出し)。7 日以内は太字。
  詳細には更新・最後の会話・消失に気づいた日時を、日時と「〜前」の両方で出す
- 区分に「データ」を足した。`data/` の中 (取ってきたデータ・アプリが作ったもの・セーブデータが混じる) は、生成物と機密の疑いを除いてデータにする
- 作り直せるものや道具が書いたものが「個人」に入っていたのを直した (手元の記録で 26,322 件 → 2,879 件。うち 2,289 件はデータへ)
  - 生成物: 名前の違う venv (`*-venv`・`*_venv`)・`site-packages`・`.godot`・`.cxx`・入れ子の `.git`・`*_cache`・ソースマップ。
    名前で分からなくても `pyvenv.cfg`・`CACHEDIR.TAG`・`base_library.zip` (PyInstaller) のあるフォルダは生成物にする
  - 道具のデータ: `shots`・`_check`・`output`・`backups`・`*_backups` の中と `.bak`。
    `tools`・`research` (道具の置き場と、Claude が調べものをするときに作る場所) の中の、無視されて残っているもの
  - 1 つのフォルダの下にファイルが 1000 件を超えれば (地図のタイルなど)、道具のデータの 1 件に畳む。
    機密の疑いが混じるフォルダと、区分を付け替えたフォルダは畳まない
  - Flutter・Capacitor のプロジェクト (`pubspec.yaml`・`capacitor.config.*` のある所) の `android/`・`ios/`・`macos/`・`linux/`・`windows/`・`web/` の中で
    無視されているファイルは生成物にする (雛形と作り直されるもの)。フォルダごとは畳まず、機密らしい名前は機密の疑いのまま。
    名前でも `ephemeral`・`gradlew`・`gradle-wrapper.jar`・`*.iml` は生成物、無視されている `config` の中は道具のデータ (アプリが書いた状態)
  - Cloudflare Workers の設定 (`wrangler.jsonc`・`wrangler.toml`) に書かれた配るファイルの置き場 (`assets.directory`・`site.bucket`) の中は生成物
  - 道具のデータ: 無視されている `storage` の中 (アプリが保存したもの)。生成物: 取ってきた学習済みのモデル (`tessdata*`・`*_models`・`.onnx`・`.traineddata`・`.safetensors` など)
  - `key.properties` (Android の署名の鍵のパスワード) を機密の疑いにした
- 資料から、Flutter・Capacitor の機種ごとのフォルダのアイコン・起動画面・`web/index.html` (git が管理する雛形) を外した
  - 同梱のライブラリの中の `tokens.py` などが機密の疑いになっていたのも、これで外れる

## 0.1.2

- 詳細のボタンを「開く」(既定のアプリで開く) と「フォルダ」(エクスプローラーで場所を開く。これまでの「開く」) の 2 つにした。
  開くと実行される種類 (`.bat`・`.exe`・`.ps1`・`.vbs`・`.lnk` など) は「開く」を押せない

## 0.1.1

- `--refresh`: 窓を出さずに取り込んで終わる (RepoTether が起動時に裏で走らせる)。`--repo <フォルダ>`: そのリポジトリで絞って開く
- 取り込み・了解・区分の変更のたびに、記録の隣へ `summary.json` (リポジトリごとの印の数。ファイル名は書かない) を書く。RepoTether がこれを読んで行に札を出す
- 画面と裏の取り込みが同時に記録を書いても、失敗させずに待つ

## 0.1.0

最初の版。

- gitignore された手元のファイルをリポジトリごとに洗い出し、「生成物 / 機密の疑い / 道具のデータ / 個人」に分けて記録する。中身は読まない。分け方はフォルダかファイルの単位で付け替えられる
- 前回と比べて、消えた・動いた (同じ中身が別の場所に現れた)・戻った・リポジトリごと見当たらない、を印にする。「了解」で印から外す
- Claude Code の会話の記録から、ファイルが会話に出た場面と出方 (読込・添付・検索・編集・命令・作成・結果・本文) を拾う。機密の疑いのファイルの中身が会話に出たら印にする
- 会話の場面を押すと、前後のやり取りを開く。人と Claude の文は Markdown を組んで表示し、「原文」で元の文字に戻せる。種類ごとに隠せる
- git が管理する資料 (md・画像・動画・音声・Office・PDF・HTML) も一緒に探せる
- 検索・区分・状態・会話・リポジトリ・拡張子で絞る。表示は一覧とツリーを切り替える
- 通信しない (依存と CSP を試験で確かめる)。記録が同期フォルダの下なら開かない
